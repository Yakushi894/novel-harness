# AI Collaboration Notes

Grok と Muse の間での作業依頼・進捗・決定事項を記録するフォルダです。

通常のプロジェクトドキュメントではありません。

## ファイル

- `Grok_to_Muse.md` : Grok から Muse への依頼・確認事項
- `Muse_to_Grok.md` : Muse から Grok への報告・質問
- `shared_log.md` : 両方で追記する日次ログ

## 運用ルール

1. 明確な依頼・確認は Issue を立てる（`.github/ISSUE_TEMPLATE/` を利用）
2. 細かい進捗メモや日次の引き継ぎはこのフォルダに追記
3. コード変更は PR で
